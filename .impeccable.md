# Design Context for Bartlett Labs

## Brand Identity

**Brand Persona:** The Nerdy Hillbilly — Purdue Engineer meets Small-Town Handshake

**Voice:** Direct, honest, no fluff. Solutions-focused. "Real work for real businesses."

## Visual Direction

**Aesthetic:** Modern Workshop — contemporary but grounded, technical but approachable, built to last.

## Color Palette (WCAG AA Compliant)

### Primary Colors
- **Warm Parchment** `#F5F3F0` — Dominant surface, backgrounds, cards
- **Houston Navy** `#03202F` — Primary text, headings, deep accents
- **Astros Orange** `#FF5910` — Primary accent, CTAs, emphasis (high contrast on light)
- **macOS Mail Blue** `#007AFF` — Secondary accent, links, highlights

### Neutrals
- **Text Primary:** `#03202F` (Houston Navy, not black)
- **Text Muted:** `#6b7280` (warm gray, tinted toward navy)
- **Border:** `#e5e3e0` (tinted toward parchment)

### Derived Colors
- **Navy Light:** `#0a3a52` — Hover states, depth
- **Orange Dark:** `#D44D0A` — Button hover states
- **Navy Dark:** `#03202F` — Footer backgrounds

## Typography

### Display Font
- **Font Family:** Roboto Slab or Arvo
- **Usage:** Headings (h1-h4), page titles, section intros, labels
- **Weight:** 600–700
- **Purpose:** Creates visual hierarchy and "workshop" aesthetic

### Body Font
- **Font Family:** Inter (sans-serif)
- **Usage:** Body text, paragraphs, form fields, meta information
- **Weight:** 400–600
- **Line Height:** 1.6–1.85 for body, 1.15–1.3 for headings

### Monospace
- **Font Family:** IBM Plex Mono
- **Usage:** Code blocks, timestamps, technical labels

## Type Scale
```
h1: clamp(2.5rem, 5vw, 3.5rem) / 1.2
h2: clamp(1.8rem, 3vw, 2.5rem) / 1.15
h3: clamp(1.3rem, 2.2vw, 1.7rem) / 1.2
p: 1rem–1.125rem / 1.6–1.85
small: 0.875rem / 1.6
```

## Spacing & Layout

### Spacing Scale (4pt base)
- **xs:** 4px (gaps between inline elements)
- **sm:** 8px (tight groupings)
- **md:** 12px (standard gap)
- **lg:** 16px (comfortable breathing)
- **xl:** 24px (section separation)
- **2xl:** 32px (major rhythm)
- **3xl:** 48px (page section padding)

### Container
- **Max width:** 78rem
- **Padding:** 1.5rem mobile, 2rem desktop
- **Breakpoints:** Tailwind defaults (sm: 640px, md: 768px, lg: 1024px, xl: 1280px)

## Interaction Design

### Animations
- **Framework:** Framer Motion
- **Physics:** spring({ mass: 1, tension: 170, friction: 26 })
- **Transitions:** 160–180ms for interactive states, 300–500ms for page transitions

### Buttons
- **Primary:** Astros Orange background, white text, shadow on hover (lift effect)
- **Secondary:** Parchment background, navy text, subtle border
- **Ghost:** Transparent, outline, navy text

### Interactive Elements
- **Links:** macOS Mail Blue, underline on hover
- **Form inputs:** 1px border in neutral, focus outline in Astros Orange
- **Cards:** Warm parchment with 1px subtle border, lift on hover (transform: translateY(-3px))
- **Focus states:** 2px solid outline in Astros Orange, 3px offset

## Absolute Design Rules

### DO
- Use Houston Navy for all primary text (not pure black)
- Use Astros Orange sparingly for high-impact moments (CTAs, focus states, emphasis)
- Apply semantic spacing from the 4pt scale
- Use display font for headings to establish "workshop" aesthetic
- Create clear hierarchy: h1 > h2 > h3 > body
- Use cards with lift effect (translateY(-3px) on hover)
- Pair form fields with clear labels and macOS Mail Blue focus rings

### DO NOT
- Use side-stripe borders (border-left/right > 1px) on cards, callouts, or alerts
- Use gradient text for any content
- Use glassmorphism decoratively; only if purposeful for layering/depth
- Mix fonts arbitrarily; stick to the display + body + mono palette
- Use pure black (#000) or pure white (#fff); always tint toward brand
- Hide functionality on mobile; adapt the interface instead
- Repeat information (titles in headers and cards duplicated)
- Use cyan (#0891b2) — it's been replaced with macOS Mail Blue (#007AFF)

## Responsive Design

- **Mobile-first:** Build for 320px minimum, scale up
- **Typography:** Use fluid clamp() on headings, fixed rem on body
- **Navigation:** Hidden on mobile (< 1024px), visible desktop
- **Grid:** Use auto-fit/auto-fill for flexible layouts
- **Images:** Max-width: 100%, border-radius: 1.5rem, 1px border

## Component Patterns

### Cards
- Background: Warm Parchment with subtle gradient
- Border: 1px rgba(229, 227, 224, 0.8)
- Padding: 1.5rem–2rem
- Hover: lift effect + shadow increase

### Badges / Labels
- Font: IBM Plex Mono, 0.72rem, uppercase
- Color: Navy text on transparent (or subtle background)
- Spacing: 0.65rem gap between text and leading line

### Forms
- Label: body text in navy
- Input: 1px border in neutral, padding 0.75rem
- Focus: 2px Astros Orange outline, 3px offset
- Error: Astros Orange text, border in orange
- Success: Teal accent

### Blockquotes
- Background: Linear gradient (orange to transparent) + subtle overlay
- Border: 1px subtle orange
- Padding: 1.25rem
- Style: Italic, 1.05rem size, 1.8 line-height

## Known Constraints

- No external animations or decorative moving elements beyond Framer Motion
- Ensure color contrast is WCAG AA minimum
- Mobile viewport minimum: 320px
- Next.js 14+ with Tailwind CSS
- Supports light mode only (current implementation)
